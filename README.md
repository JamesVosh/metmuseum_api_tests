# Тесты для API Музея Метрополитен

Набор автоматизированных тестов для проверки функциональности API Музея Метрополитен (https://metmuseum.github.io) на основе Python 3.13 и библиотек Pytest, Pydantic, Requests, logging, httpx

## Установка

1) git clone <URL_репозитория>

2) cd <папка_проекта>

3) python -m venv .venv

### For Linux/macOS
4) source .venv/bin/activate

### For Windows
4) .venv\Scripts\activate

5) pip install -r requirements.txt

6) pytest
